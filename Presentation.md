# Coloring Book
## L’application de coloriage créatif premium – 100 % offline, sans pub, sans compte

## Présentation
Coloring Book est une application mobile premium iOS & Android (développée avec React + TypeScript + Capacitor), pensée **offline-first** et **mobile-first**, qui permet à chacun de créer et colorier ses propres livres de coloriage personnalisés avec une qualité professionnelle.

Inspirée de la simplicité de Canva pour la composition et du plaisir addictif des meilleures apps de coloriage (Lake, Pigment, Recolor), elle combine :
- Un éditeur puissant pour assembler des scènes avec des milliers de dessins vectoriels (SVG) de haute qualité
- Un moteur de coloriage ultra-fluide sur canvas HTML (pinceau, pot de peinture, zoom/pan tactile parfait)
- Une expérience 100 % hors ligne : pas de compte, pas de pub, pas de connexion obligatoire
- Export PDF haute résolution et impression directe

Démo sur demande.


## Fonctionnalités clés

- **Création de livres virtuels** : Création et organisation de livres de coloriage personnalisés avec gestion avancée des pages et contenu.

- **Gestion des pages** : Ajout et organisation de pages pour créer un livre de coloriage personnalisé, avec une interface mobile first pour une navigation fluide sur tous les appareils.

- **Composition graphique Canva-like** : Bibliothèque d'assets prédéfinis de haute qualité (dessins, cadres, textes) pour personnaliser les scènes de manière intuitive, avec un drag-and-drop simple et des outils d'édition inspirés de Canva.

- **Coloriage interactif** : Outils de remplissage de forme unis, en dégradé, pinceaux tels que l'aquarelle pour colorier les formes directement sur un canvas SVG, avec des outils avancés pour une expérience ludique comme dans une app de coloriage dédiée (zoom, pinceaux, undo/redo).

- **Interactions avancées** : Gestion poussée des interactions touch et desktop (panning, pinch, zoom, animations) pour une expérience utilisateur fluide, optimisée pour le mobile et le offline.

- **Export et sauvegarde offline first** : Export PDF haute qualité, impression, sauvegarde locale des données sur fichier (fonctionne hors ligne), et possibilité d’import/export cloud pour la synchronisation.

- **Support mobile** : Conception mobile first avec optimisation responsive, intégration iOS via Capacitor, et interactions touch prioritaires pour une utilisation nomade.

- **Accessibilité** : Thème sombre pour un meilleur confort visuel, et support offline pour une accessibilité partout, sans connexion requise.

## Stack technique

- **Front-End** : TypeScript, React, Redux, Fabric.js, TailwindCSS, Capacitor (intégration iOS), avec un focus sur le offline first via service workers et stockage local.

- **Technologies spécifiques** : Canvas SVG pour les dessins interactifs, avec des outils en HTML pour une composition Canva-like et un coloriage immersif.

- **Infrastructure** : GitHub pour le versionning, Render.com pour le déploiement et la CI/CD.

## Résultats

Coloring Book offre une expérience fluide et des visuels vectoriels de haute qualité grâce à l’utilisation d’un canvas SVG, garantissant un rendu professionnel même en mode offline. Ce projet permet de maîtriser la gestion d’un canvas SVG interactif, d’approfondir les compétences en React, Redux, et animations touch, et de relever des défis techniques comme l’optimisation offline et mobile first. Bien qu’en phase alpha, l’application a le potentiel de devenir une solution créative pour deux publics cibles :

- Les utilisateurs de tout âge cherchant une activité ludique pour passer le temps, créer quelques dessins et les partager avec leurs proches, comme dans une app de coloriage simple.

- Les créateurs de contenu souhaitant concevoir des livres de coloriage professionnels pour les vendre sur des plateformes comme Amazon, avec des outils d'édition intuitifs inspirés de Canva.

### Guide d'utilisation des images

**Pour Canva :**
- Téléchargez les images depuis le dossier `images/` vers votre ordinateur
- Importez-les directement dans votre design Canva

**Pour Google Docs :**
- Hébergez les images sur un service comme Imgur, GitHub, ou Google Drive
- Remplacez les chemins relatifs par les URLs des images hébergées
- Copiez-collez le contenu Markdown dans un document Google Docs (il reconnaîtra automatiquement les liens d'images)

**Pour d'autres outils :**
- Les chemins relatifs fonctionnent dans la plupart des visualiseurs Markdown
- Pour une utilisation professionnelle, hébergez les images en ligne
